# Support

## Look it up

- The [user guide](/guide/) covers every screen and setting.
- [Troubleshooting](/guide/troubleshooting/) explains the error messages and what to try.

## Report a problem or ask for a feature

Open an issue on [GitHub](https://github.com/Singlbase-Technologies-Limited/apollo-download-manager/issues). Say which version you use (Settings, About and diagnostics), on which system, and what happened.

A diagnostics report helps: in the app, open Settings, About and diagnostics, and choose **Export diagnostics…** to save it to a file you can attach. Passwords, cookies, tokens, tracker passkeys and keys are removed from it. Read it before you share it.

## Security problems

Please don't report a security problem in a public issue. Use GitHub's private vulnerability reporting on the [security page](https://github.com/Singlbase-Technologies-Limited/apollo-download-manager/security).
